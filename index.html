Flashed — now power it up

  1. Unplug the USB cable and plug it back in to reboot into TerraLync Lite.
  2. On your phone or laptop, join the TerraLync-Setup Wi-Fi network (open — no password).
  3. The setup page should pop up automatically. If not, open http://192.168.4.1/config.
  4. After Wi-Fi is configured, reach the dashboard at http://terralync.local.
No device showing up, or flash failing?

Board not in the picker? Check the USB cable first — a charge-only cable powers the board but never enumerates. ESP32-S3-GEEK running TerraLync already? Its app-mode USB can't be flashed — unplug, hold BOOT, reconnect, release BOOT: it reappears as an "Espressif" device.

Drivers. Boards connected via their native USB-C port (Espressif device) need no driver on Windows 10/11, macOS, Linux or ChromeOS. Boards with a CH340 chip (the Guition display) work out of the box on Windows and modern macOS — older macOS may need the free WCH CH34x driver. On Linux, add yourself to the dialout group (sudo usermod -aG dialout $USER, then sign out and back in) or Chrome can't open the port.

Port in use? Only one program can hold a serial port — close Arduino Serial Monitor, PuTTY, or any other browser tab connected to the device, then Connect again.

Flash failing part-way? Under Advanced, set Baud to 115200 (safe) and retry. If it still fails, copy the log below and send it to us.

Still stuck? The Windows flasher (.exe) is the fully-tested path — or check the install guide.
